**Label**: `fsm`, `critical`, `refactor`  
**Prioridade**: 🔴 **Crítica**  
**Tempo**: 4 horas (mais longa)  
**Dependências**: Issue #3, Issue #4

**Descrição**:
Implementar a máquina de estados de 7 estados (IDLE → LIFTOFF → BURNOUT → APOGEE → FREEFALL → PARACHUTE → LANDED) baseada no código Python **validado** (`extras/FSM_tester/FSM_Tester.py`).

**⚠️ ATENÇÃO**: Esta é a issue mais crítica do projeto. A FSM controla o deploy do paraquedas.

**Tarefas**:
- [ ] Criar `firmware/flight/FlightStateMachine.h`
- [ ] Criar `firmware/flight/FlightStateMachine.cpp`
- [ ] Implementar enum `FlightState`:
  ```cpp
  enum FlightState {
    IDLE = 0, LIFTOFF = 1, BURNOUT = 2, 
    APOGEE = 3, FREEFALL = 4, PARACHUTE = 5, LANDED = 6
  };
  ```
- [ ] Implementar funções de detecção **exatamente como no Python validado**:
  - `bool detectLiftoff()` - `totalAccel > 15 && height > 5`
  - `bool detectBurnout()` - `az < -8 || totalAccel < 2`
  - `bool detectApogee()` - `|vz| < 1 && az < -0.1`
  - `bool detectFreefall()` - `totalAccel < 11.5 && vz < -5`
  - `bool detectParachute()` - `altitude < 750 || |vz| > 80 || drop > 10`
  - `bool detectLanded()` - `|vz| < 0.5 && height < 10`
- [ ] Implementar validações de segurança:
  - NaN/Inf checks em todos os valores
  - State guards (altura > 5m para liftoff)
  - Timeouts para evitar stuck states (30s por estado)
- [ ] Adicionar logging de transições
- [ ] Testar com dados reais: `extras/FSM_tester/flight_inserter.py`

**Critérios de Aceitação**:
- FSM detecta todos os 7 estados corretamente com dados reais
- Thresholds validados com `13_30_11-Dados.csv` (1.873 pontos)
- Sem transições falsas (false positives)
- Timeouts funcionam (não trava em nenhum estado)
- Deploy de paraquedas **APENAS no estado FREEFALL** e com condições corretas

**Referência**: 
- `firmware/REFACTORING_PLAN.md` - Fase 6
- `extras/FSM_tester/FSM_Tester.py` - Código Python validado
